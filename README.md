# social-media-files

Public media for Mohsin Habib's scheduled social media posts (TikTok, Instagram, Facebook, YouTube, LinkedIn).
Files here are linked from Metricool, so they must stay public. Only approved content is added.

- `videos/` – finished vertical videos (1080x1920 MP4)
- `content/<date>-<slug>/` – carousel slides, covers, and the JSON each was rendered from
- `tools/render_video.py` – `python3 tools/render_video.py scenes.json out.mp4` (branded video + original music)
- `tools/render_carousel.py` – `python3 tools/render_carousel.py slides.json out_dir/` (1080x1350 slides)
